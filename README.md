# Gra w kółko i krzyżyk z GUI
Noughts and Crosses ⭕✖️⭕

Projekt stworzony w Pythonie w ramach nauki programowania obiektowego i obsługi GUI z użyciem biblioteki `wxPython`.

## Opis
Gra w kółko i krzyżyk dla dwóch graczy: użytkowników lub użytkownika i komputera. Interfejs graficzny umożliwia wprowadzenie imion, wybór trybu gry i pierwszego gracza. Program informuje o wygranej lub remisie i pozwala zresetować rozgrywkę.

Ten projekt był moją `pierwszą próbą programowania obiektowego` i `pierwszym doświadczeniem z GUI` w wxPython.

## Funkcje
- Gra dla 2 graczy (z komputerem lub drugim użytkownikiem)
- Graficzna plansza 3x3 z przyciskami
- Wybór imion i trybu gry
- Losowe ruchy komputera
- Detekcja zwycięzcy i remisu
- Obsługa zdarzeń i interakcji użytkownika
- Możliwość resetowania gry
